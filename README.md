# dungeonescape
Unreal Engine 5 mini game built with C++ and blueprints, focused on enemy AI, player animations, game logic, and level design.
Gameplay Demo: [https://youtu.be/OXTVWURAa5s](https://youtu.be/adnMvzLw8Lk)

## Features
  - Enemy AI states (Idle, Alert, Investigating)
  - Player movement animation using 3D models
  - Gun/weapon logic
  - Health bar using GUI to track health
